# 안녕하세요, 소프트웨어 품질 확보를 위한 QA 엔지니어 오석희입니다.

> 수동 테스팅의 효율화와 자동화 프레임워크 구축을 통해 서비스 안정성을 높이는 것을 목표로 합니다.

### Project Goal
- Python 기반의 테스트 자동화 프레임워크 설계 및 고도화
- SDK(Auth, Billing, AD) 통신 구조 분석 및 검증 프로세스 정립
- CI/CD 파이프라인 연동을 통한 테스트 효율 개선

### Tech Stack
- Language: Python, SQL
- Automation: Appium, Selenium, Pytest
- Tools: PyCharm, Git, Charles Proxy

### Roadmap
- Python 기초 및 객체지향 프로그래밍 숙달
- 모바일 환경에서의 UI/UX 자동화 시나리오 구축
- 데이터 정합성 검증을 위한 데이터베이스 쿼리 고도화

---
꾸준한 기술 학습을 통해 신뢰할 수 있는 소프트웨어를 만듭니다.
